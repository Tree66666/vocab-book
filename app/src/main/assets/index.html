📖 软件使用说明

1. 这是什么
拍下整篇英语阅读理解，App 自动识别你用笔圈画的生词（黑笔 / 红笔均可）；不圈画也没关系，选「智能选词」让 AI 通读全文、自动挑出考研高频难词。一键生成带音标、释义、原文例句的生词卡片，按遗忘曲线安排复习，助你高效背单词。

2. 首次使用：配置 API
「我的 → API 设置」选择渠道（OpenCode Go 或 DeepSeek 官方 API），粘贴你的 API Key，点「保存设置」再点「测试连接」确认可用。Key 只存在本机。

3. 拍照识别
「上传」页拍照或从相册选图（可多选、自动压缩）。选择识别模式：
· 自动判断：任意颜色圈画均识别
· 黑笔圈画 / 红笔圈写：只识别对应颜色笔迹
· 智能选词：不看圈画，AI 通读全文挑选重要难词
点「开始识别」，每张图独立进度，失败可单独重试。

4. 生词管理
识别结果可逐词编辑 / 删除，确认后存入生词本。生词本支持搜索、按掌握度筛选、按考研词频排序，支持有道查词与一键复核释义，也可手动输入单词（有道自动补全）。

5. 复习
「复习」页按艾宾浩斯遗忘曲线（SM-2）调度到期单词，闪卡模式为主：看单词回忆释义，翻面听发音验证，按「忘记 / 有点印象 / 记得」评分自动安排下次间隔，间隔满 21 天标记「已掌握」。

6. 数据与隐私
全部数据（生词、复习记录、设置）只存本机，无账号、无云端。识别图片会自动存到系统相册「生词错题本」目录。可在「我的 → 数据导出」导出 CSV / JSON / Anki / PDF 备份。
