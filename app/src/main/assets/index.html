复习说明

基于艾宾浩斯遗忘曲线（SM-2 算法）调度，闪卡采用「先回忆 → 再看例句 → 最后看释义」三阶段自测：看单词先凭记忆作答，选「记得」直接看释义；选「不记得」会先显示例句提示再作答一次。评分自动安排下次间隔（1天→3天→7天→14天→30天…，忘记的词当天重看一次加深记忆）。复习间隔满 21 天自动标记为「已掌握」，之后进入「熟词巩固」池：不设固定间隔、不进到期调度，随机循环抽看即可；觉得不熟可随时降回活跃池重新学。

📖 软件使用说明

1. 这是什么
拍下整篇英语阅读理解，AI 通读全文智能挑出值得背的生词，纸面圈画 / 划线作为参考信号；一键生成带音标、释义、原文例句的生词卡片，按遗忘曲线安排复习，助你高效背单词。

2. 首次使用：配置 API
「我的 → API 设置」选择渠道（OpenCode Go 或 DeepSeek 官方 API），粘贴你的 API Key，点「保存设置」再点「测试连接」确认可用。Key 只存在本机。

3. 拍照识别
「上传」页拍照或从相册选图（可多选、自动压缩，默认并发 3 张识别、按上传次序归并）。可选用选词侧重预设（多收录 / 圈画优先 / 精挑少收），也可手写本次补充说明。AI 会区分真正影响理解的生词与做题过程勾画，并标注正常 / 过于基础 / 冷僻生僻供你审阅；每张图独立进度，失败可单独重试。

4. 生词管理
识别结果可逐词编辑 / 删除，也可勾选批量删除，确认后存入生词本。生词本支持搜索、按掌握度筛选、按考研词频排序，支持有道查词与一键复核释义，也可手动输入单词（有道自动补全）。「拓展池」补充派生 / 易混 / 搭配关联词，人工确认后收录。

5. 复习
「复习」页按艾宾浩斯遗忘曲线（SM-2）调度到期单词，闪卡模式为主、三阶段自测：先看单词凭记忆作答（记得→直接看释义；不记得→先看例句提示再答一次），揭示释义后自动发音验证。按「记得 / 有印象 / 不记得」评分安排下次间隔（1→3→7→14→30 天，忘记的词当天重看），间隔满 21 天标记「已掌握」；已掌握的词进入「熟词巩固」随机循环复习，有空过一眼即可，不熟可降回活跃池重新学。

6. 数据与隐私
全部数据（生词、复习记录、设置）只存本机，无账号、无云端。识别图片会自动存到系统相册「生词错题本」目录。可在「我的 → 数据导出」导出 CSV / JSON / Anki / PDF 备份。
