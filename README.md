# 生词错题本（VocabBook）· 开源版

面向英语学习者的「拍照生词错题本」Android 应用。

**核心亮点：拍下整篇英语阅读理解，App 自动识别你用笔圈画的生词（黑笔 / 红笔均可）；不圈画也可以，切到「智能选词」让 AI 通读全文、自动挑出考研高频难词——一键生成带音标、释义、原文例句的生词卡片，按遗忘曲线（SM-2）安排复习。智能选词还会记录你每次「采纳 / 丢弃」的反馈，定期让 AI 自己总结成一份带具体词例的「策略卡」，之后自动喂回给识别提示词，越用越贴合你的真实词汇水平。**

**纯单机**：无账号、无云端、数据只存手机本地。AI 识别仅在拍照上传时联网调用，AI 渠道与 API Key 由用户自行填写（OpenCode Go / DeepSeek 官方二选一），模型固定 `deepseek-v4.1-flash`。

## 功能

| 模块 | 能力 |
|---|---|
| 拍照识别 | 拍整篇阅读理解 → AI 自动识别圈画生词（黑笔 / 红笔 / 任意颜色 / 智能选词四模式，智能选词自动挑考研高频词）→ 每张图独立进度；**成功一张即可边识别边编辑 / 转入，失败可单张重试或确认忽略，转入后失败图保留待重试** → 卡片结果可编辑 → 确认入库；**例句内任意单词可点击一键快录** |
| 智能选词 | **AI 自维护提示词**：记录每个候选词的采纳 / 丢弃 / 是否编辑反馈（仅 smart 模式）→ 反馈攒够（≥5 条）后 AI 依据具体词例总结出「策略卡」（难度线 + 优先选 / 不要选 + 具体例子 + 选词数量 + 数字依据），下次 smart 识别自动注入；**自动触发**（累积 ≥3 次会话且距上次更新 ≥7 天）或手动更新均可，可一键重置回默认 |
| 页面滚动 | 右侧可拖动滚动进度条，长列表 / 长页面快速定位 |
| 生词本 | 搜索、掌握度筛选（陌生 / 已掌握）、考研词频排序、编辑 / 删除、**查词 / 手动录入**（以查词为主：输入即联想有道释义，也可顺手补充例句、词性）、**录入前先看该词的考研真题词频（是否收录、出现几次、大纲内外）再决定收不收**、一键复核释义（**只扫未核实词，已核实自动跳过**）、**反复录入词自动优先（录入 ×N 徽章）**、编辑弹窗点外部可关闭 |
| 复习 | 闪卡为主、**三阶段自测**（先凭记忆作答：记得→直接看释义；不记得→先看例句提示再答一次），**卡片标注考研词频重要程度 + 具体信号徽章（录入 ×N 次 / 忘记 N 次 / 上次记得与否）**，SM-2 温和间隔调度（1→3→7→14→30 天），**忘记的词当天重看一次**，**到期队列按「录入次数 + 历史忘记次数」加权、重要难词优先**，间隔满 21 天标记「已掌握」，**已掌握词 30 天左右定期回归复习** |
| 统计 | 今日新增、累计生词、今日复习、掌握率、掌握度分布、AI token 消耗（OpenCode / DeepSeek 分开统计） |
| 导出 | 生词本 CSV / JSON / Anki / PDF；学习日志 CSV / JSON；一键分享调试日志 |
| 发音 | 联网（有道）发音优先、系统 TTS 离线兜底；**词卡 / 编辑弹窗打开默认自动发音**，复习揭示释义后自动发音（美音 / 英音可选） |
| 自动更新 | 启动时静默检查 / 「我的」页手动检查 GitHub 新版本，一键下载安装，无需手动换包 |
| 界面 | 蓝紫渐变 + 冷白背景、柔和阴影，**极简高级 app 图标（线性书签）**；页面 / 闪卡切换淡入、荧光笔绘制等克制微动画（支持系统「减少动态效果」）；待识别缩略图点按**大图预览**、左上角显式 ✕ 删除，不再误触删图 |

## 环境要求

- JDK 17
- Android SDK（compileSdk 34 / minSdk 24 / targetSdk 34）
- Gradle 8.5（工程自带 wrapper）

## 安装包

- 可直接安装：`release/vocab-book-v1.0.29.apk`（Android 7.0+，arm64 设备）
- 或自行构建（见下）

## 构建

```bash
# 命令行构建（调试包）
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

或用 Android Studio 打开本目录，等待 Gradle Sync 后 Build > Build APK(s)。

## 使用说明

1. **首次使用**：「我的 → API 设置」选择渠道（OpenCode Go 或 DeepSeek 官方 API），粘贴你自己的 API Key，保存后点「测试连接」确认可用。Key 仅保存在本机应用私有存储。
2. **拍照识别**：「上传」页拍下整篇阅读理解（可多选）。识别模式默认「智能选词」（AI 通读全文挑重要难词与考研高频词，圈画/划线的词会作为参考信号适当优先、但非最高优先级），也可切换自动判断（任意颜色圈画）/ 黑笔圈画 / 红笔圈写。
3. **生词管理**：识别结果逐词编辑 / 删除后存入生词本；支持「查词 / 手动录入」一个入口完成查词与收录——输入英文即时联想有道释义，并在录入前显示该词在考研真题词频库里的位置（没收录 / 出现几次 / 大纲内外），作为要不要收的参考；也支持考研词频排序。**同一个词被反复录入（不同篇里又圈画了它）会自动提高优先级**：生词本默认按录入次数排序并显示「录入 ×N」徽章，复习时这类词优先出现。
4. **复习**：「复习」页按遗忘曲线调度到期单词（反复录入的词优先），闪卡模式翻面验证、三档评分。
5. **导出备份**：「我的 → 数据导出」，支持 CSV / JSON / Anki / PDF。
6. **更新**：「我的 → 检查更新」（或 App 启动时自动静默检查）。发现新版本确认后自动下载，下载完成系统提示安装（Android 8+ 首次安装需在系统弹窗中允许「安装未知应用」）。

## 架构

```
assets/index.html  ── 前端单页（上传 / 生词本 / 复习 / 统计 / 我的）
        │  WebView + addJavascriptInterface（WordBook 桥）
        ▼
MainActivity ──┬── WordDb.kt     本地 SQLite（words + review_records，SM-2 调度）
               ├── AiClient.kt   AI 识别客户端（OpenCode / DeepSeek 双渠道，Key 动态读取）
               ├── YoudaoClient.kt  有道查词 / 发音兜底
               ├── WordFreq.kt   考研词频（assets/kaoyan.json）
               └── Exporter.kt   导出 CSV / JSON / Anki / PDF
```

## 数据与隐私

- 全部数据（生词、复习记录、设置、API Key）只存本机，无任何云端存储与账号系统
- API Key 仅保存在应用私有 SharedPreferences，不写入代码、不上传
- 拍照识别的图片会自动保存到系统相册「生词错题本」目录（从相册选图上传不重复保存）
- 数据库位于应用私有目录 `wordbook.db`（卸载会清除，请定期导出备份）

## 词频数据

`app/src/main/assets/kaoyan.json`：考研英语 46 套真题句频榜（第三方统计，非官方），含 1199 个高频词及频次，用于生词排序与重要性提示。
